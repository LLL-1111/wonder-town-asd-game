# 奇妙小镇 · 阶段 0 / 阶段 A 原型

面向 ASD 儿童与家长共用一台横屏平板的亲子互动同步性训练游戏。本版本完成基础框架、关键技术验证台，以及《超市大忙碌》中的首个完整示范《补货大作战》。其余 13 个游戏只登记在统一目录中，尚未实现玩法。

## 本地运行

环境要求：Node.js 20.19+ 或 22.12+，pnpm 11。

```bash
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:5173`。生产构建和同步判定测试：

```bash
pnpm test
pnpm build
```

## 已实现

- 首页、训练/测试分流、T0/T1 选择、四领域入口、14 个游戏目录。
- 统一训练/测试会话、试次、事件与版本字段；IndexedDB 本地存储；JSON/CSV 导出。
- 阶段 0 技术验证台：双活动触点、共同保持、麦克风、前置摄像头、IndexedDB 与导出。
- 《补货大作战》训练：L1→L2→L3 自动升级，每级按固定机会数前进，不以成功率设门槛。
- 《补货大作战》测试：T0/T1 使用同一材料集、同一顺序与固定参数，不使用训练难度。
- 基于真实试次的 T0/T1 描述性结果对比；没有数据时不生成结果。

## 重要验证边界

当前采用“同一商品内的儿童侧 / 家长侧”身份分区原型。它能稳定给浏览器事件分配角色，同时保留同一 `target_id`，但不能从硬件层证明某根手指属于谁。真实 iPad 与 Android 平板的双人多点触控、误触、手掌干扰、权限及性能验收仍待执行，因此界面和数据均明确标记为“待真实平板验证”。

详细结论见 [阶段 0 技术验证记录](docs/STAGE_0_VALIDATION.md)。
